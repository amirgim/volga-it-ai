# Пояснительная записка

## 1. Источники данных

- Собственная съёмка на парковках, у шлагбаумов, с рук.
- Открытые фотобанки с лицензиями, допускающими некоммерческое использование.
- Публичные датасеты с совместимыми лицензиями (фиксируются в `meta.csv`).
- Синтетика, генерируемая `generator/generate.py` (seed = 42).

Для каждого реального изображения в `meta.csv` заполнены поля `source`, `license`,
`conditions`. Запрещённые источники не использовались.

## 2. Методика сбора и генерации

Реальные данные размечаются вручную: `plate_num`, `plate_type`, `bbox`, `quad`,
`is_vehicle`, `conditions`. Нечитаемые символы заменяются на `#`.

Синтетика: рендер номера (белый / жёлтый / двухстрочный), затем
перспективные искажения, размытие, шум. Пропорции типов: 30/30/30/10.

## 3. Архитектура

Двухстадийный пайплайн.

1. Детектор YOLOv8n/s, 4 класса: `type1`, `type1a`, `type1b`, `other`.
   Экспорт в ONNX FP16.
2. OCR CRNN (CNN + BiLSTM + CTC), вход 1×32×128, алфавит
   `0-9ABEKMHOPCTYX` + blank. Экспорт в ONNX FP16.
3. Постобработка: нормализация кириллических глифов в латиницу,
   маскирование символов с confidence < 0.5 в `#`, проверка маски номера
   и правила региона (2 цифры или 3 цифры, начинающиеся с 1 / 2 / 7).

`other` не выводится в CSV, чтобы не портить метрики.

Обоснование: YOLO — самая дешёвая по времени детекция на GTX 1050 Ti;
CRNN — минимальная OCR-модель, укладывающаяся в бюджет 100 мс.
Расширение на новые типы знаков/страны — добавление класса в детектор
и символов в алфавит OCR.

## 4. Замеры скорости

Референс: Intel Core i5-7600, GTX 1050 Ti 4 GB, 16 GB RAM.
ONNX Runtime + CUDA + FP16. Среднее время на изображение — см. вывод
`python run.py` (поле `avg_ms`). Цель — ≤100 мс.

## 5. Известные ограничения

- Сильно загрязнённые и ночные кадры — точность падает.
- Мелкие знаки в кадре требуют апскейла детектора до 960 px.
- Регион из 3 цифр при плохом OCR может быть ошибочно принят за 2 цифры;
  постобработка проверяет правило 1/2/7.

## 6. Идеи расширения

- Добавить типы 2, 3 (прицепы, мотоциклы) — новые классы + символы.
- Мультистрановая поддержка — отдельная голова OCR на страну.
- Квантизация INT8 для CPU-инференса.
