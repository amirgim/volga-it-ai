# Записка к решению (полуфинал, ИИ и анализ данных)

## Что сделано
- YOLOv8n-детектор (fine-tune на синтетике) + CRNN-CTC OCR (ONNX).
- type1a (квадратные) разворачиваются в одну строку (src/unfold.py).
- Постобработка: ГОСТ-маска, позиционные замены, порог по confidence.

## Данные
- Синтетика: generator/generate.py, seed=42, ГОСТ-совместимый шрифт.
- Реальные фото: Wikimedia Commons, только свободные лицензии (см. meta.csv, колонка license).
- **Разметка dataset/labels/real получена автоматически (Haar-каскад), не вручную.** Поле plate_num/bbox/quad для реальных фото не заполнено.

## Метрики (только измеренные)
- OCR val exact-match на синтетике (отложенные номера): **0.825**.
- Скорость: avg_ms ~161 мс/кадр на нашем железе (с чтением файла); детектор+OCR отдельно — см. result.csv.

## Известные ограничения
- На реальных фото exact-match низкий из-за domain gap (шрифт, свет, качество).
- Детектор иногда срабатывает на иностранные номера; постобработка такие строки отбрасывает по формату.
- Квоты type1a/type1b/other по количеству уникальных номеров не выполнены.

## Запуск
python -m src.run --input <dir> --output result.csv --det models/yolo.pt --ocr models/crnn.onnx --device cpu
(--device cuda при наличии GPU)
